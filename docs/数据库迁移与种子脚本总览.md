## 3. 清理约定

- 每次 E2E 验证产生的数据（保单 `E2E-*`、扫码会话、员工码、测试关怀计划、测试服务关系）
  必须在验证结束后清理/回滚，不留"测试字样"数据；
- 回滚注意顺序：先删新建行（避免 active PRIMARY 唯一索引冲突），再恢复被结束的旧行，
  最后删变更日志与辅助表数据；
- 关怀计划删除按依赖序：`care_plan_execution → care_plan_occurrence → care_plan_item →
  care_plan_revision → care_plan_audit_event → care_plan`（主键为 `id`，其余表用 `plan_id`）。
