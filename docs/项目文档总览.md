**软件库迁移约定**（`jeecg-module-rehealth/src/main/resources/db/software/mysql/`）：

```text
V<yyyyMMdd>_<n>__<name>.sql        # software-db 自定义迁移，手动执行（非 Flyway）
末尾：INSERT IGNORE INTO rehealth_schema_migration(version) VALUES ('software-V<date>.<n>');
执行：docker cp 文件进 mysql 容器 → mysql < 文件（文件首行 SET NAMES utf8mb4）
```

本阶段（2026-08）保险侧迁移清单：`V20260825_1..4`（服务关系/存量迁移/保单计划列/计划目录）、
`V20260826_1..5`（经理与机构管理员权限、保单可分配、保单-用户关联表、员工码与扫码会话）。

MySQL 3306 · Redis 6379/6380 · TimescaleDB 5432 · Kafka 29092 · Nacos 8848 · Prometheus 9090。

`start-local-insurance-backend.ps1`；官网改码后重启 `start-local-api.ps1 -NoReload -Background`
（该环境 WatchFiles 重载不可靠）。

## 6. 文档同步规则（摘要）

变更前查根 `README.md` §10 的映射表：模块/接口/Schema/Kafka/模型/部署/用户可见行为各有
必同步文档。允许"文档无影响"但必须在验证说明写明原因；禁止只改实现而让
根 README、接口契约和部署说明长期失真。
